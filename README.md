# LatLomp Client Portal

Client-facing platform for LatLomp: project intake, client/admin portals, messaging, and multi-provider payments (Paystack, Flutterwave, PayPal, Crypto).

## Stack
Node.js, Express, MongoDB/Mongoose, vanilla HTML/CSS/JS, Google OAuth 2.0.

## Setup
1. `npm install`
2. Copy `.env.example` to `.env` and fill in values
3. `npm run dev`
4. Visit http://localhost:3000
